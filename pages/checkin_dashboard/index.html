选项及默认值由服务端根据当前 curl_cffi 版本动态提供。 chrome150 起的 Chrome 指纹自带 ML-DSA 签名算法，较旧的 Chrome 指纹可用下方「TLS 携带 ML-DSA」补上。
对所有站点的 curl 请求生效，包括签到、余额查询与 OAuth 登录各步。
任何站点的请求收到阿里云 WAF 的 acw_sc__v2 挑战页时，自动解算并重试一次，无需逐站配置。纯 Python 实现，不依赖浏览器或 Node.js。
由 Playwright 驱动真实的 Chrome / Edge / Chromium 打开被拦截的地址，通过 Cloudflare 托管质询后在浏览器内完成该请求（OAuth 授权一步在跳回站点前截下授权码）。 验证 Cookie 在本轮后续请求中沿用，浏览器空闲 5 分钟后自动关闭。
此功能依赖 Playwright，插件默认不安装。以下安装均在运行 AstrBot 的机器上进行（Docker 部署即容器内），与打开本页面的电脑无关。
